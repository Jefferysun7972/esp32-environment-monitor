## 📞 审核期间可能遇到的问题

### Q1: 审核被驳回 - 缺少资质
**解决**：硬件工具类目通常不需要特殊资质。如被要求：
- 提供简要的功能说明文档
- 说明这是自用工具非商业产品

### Q2: 审核被驳回 - 隐私协议不合规
**解决**：
- 检查隐私弹窗是否正常弹出
- 确保用户必须同意才能使用
- 参考 `PUBLISH_GUIDE.md` 第三部分修改

### Q3: 审核被驳回 - 功能不完整
**解决**：
- 确保 3 个页面都能正常访问
- 有真实数据展示
- 无明显 bug

### Q4: 审核超过 3 天没结果
**解决**：
- 登录微信公众平台查看状态
- 如显示"审核中"，耐心等待
- 可通过"客服咨询"催促
