## ⚠️ 五、审核注意事项

### 5.1 常见驳回原因及对策

#### ❌ 问题1：缺少隐私协议
**解决**：
- 在 `app.js` 的 `onLaunch` 中添加隐私弹窗调用
- 确保用户同意后才请求权限

```javascript
// app.js onLaunch 中添加
if (wx.requirePrivacyAuthorize) {
  wx.requirePrivacyAuthorize({
    success: () => {
      console.log('用户已同意隐私协议');
      // 继续初始化
    },
    fail: () => {
      console.log('用户拒绝隐私协议');
    }
  });
}
```

#### ❌ 问题2：类目不符
**解决**：
- 选择正确的二级类目：**工具 > 硬件工具**
- 如被要求，准备简要的功能说明文档

#### ❌ 问题3：内容不完整
**解决**：
- 确保3个页面都能正常访问
- 有真实数据展示（非空白页）
- 设置页面功能可用

#### ❌ 问题4：涉及敏感词
**避免使用**：
- "医疗"、"诊断"、"治疗"等医疗相关词汇
- "官方"、"认证"、"权威"等绝对化用语
- 价格信息（除非有支付功能）

### 5.2 审核加速技巧
1. **工作日提交**：周一至周四上午提交，审核更快
2. **描述准确**：不要夸大功能
3. **截图清晰**：使用真机截图，数据真实
4. **隐私合规**：确保隐私弹窗正常弹出
